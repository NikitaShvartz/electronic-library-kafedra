# ЛР2 — Инженерный конвейер

- [Стратегия ветвления и правила ревью](branching.md)

Базовый конвейер описан в [`.github/workflows/ci.yml`](../../.github/workflows/ci.yml). Он запускается для PR в `main`, при обновлении `main` и вручную после добавления файла в основную ветку. Для защиты `main` выберите проверку `Library checks` после её первого запуска.
