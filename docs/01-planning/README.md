# ЛР1 — навигация

Все расчёты используют исходные данные из `../../data/`. Пересчёт выполняется скриптами из `../../scripts/`.

1. `vision.md` — проблема, пользователи и критерии успеха.
2. `story-map.md` — пользовательский путь и граница MVP.
3. `backlog.md` — 17 историй с критериями приёмки и INVEST.
4. `estimates.md` — первичные оценки, итоговые SP и PERT.
5. `prioritization.md` — WSJF, ёмкость и модель выбора релиза.
6. `release-plan.md` — зависимости, критический путь, PERT и Монте-Карло.
7. `process.md` — Scrumban, доска, WIP, DoR/DoD.
8. `team-agreement.md` — рабочее соглашение.
9. `defense-notes.md` — краткие ответы на контрольные вопросы.
